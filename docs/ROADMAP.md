# BentoZip 产品路线图与竞品调研

本文档基于 BentoZip 当前已实现的架构与功能基线，对照 macOS 平台两款代表性压缩工具 **MacPacker**（开源轻量级压缩包浏览器）与 **BetterZip 6**（老牌全功能商业归档工作台），并参考 **Keka** 的格式与系统集成实践，梳理差异化定位与后续演进路线。

---

## 一、竞品深度调研（MacPacker & BetterZip 6）

### 1.1 核心浏览与档案操作

| 能力维度 | BentoZip（当前基线） | MacPacker | BetterZip 6 |
|---|---|---|---|
| 非破坏式浏览 | 原生 Finder 风格大纲视图（`NSOutlineView`），支持目录懒加载、延迟拖拽提取与窗口内 Quick Look 预览 | 类 Finder 文件夹式浏览，专注不完整解压即可查看、搜索和拖拽单个文件 | 多栏文件浏览与右侧预览窗格，无需整包解压即可直接查看、编辑 |
| 就地增删与重命名 | ZIP / 7z / TAR 支持就地添加与删除（固实 7z 与 `.tar.*` 走原子重建）；尚未支持包内直接重命名 | 支持向已有压缩包增删或替换文件（主要围绕 ZIP）并保存 | 支持 ZIP / 7z / TAR 等格式的就地增删、重命名与修改 |
| 嵌套压缩包下钻 | 暂未支持；需将内层压缩包拖出或解压后再打开 | 核心亮点，支持在窗口内直接点击进入嵌套压缩包（如 ISO 内的 ZIP、多层 `.tar.*`） | 支持在预览流程中进一步打开或处理，但不如 MacPacker 的路径式直接下钻直观 |
| 包内实时搜索过滤 | 暂未支持（目前仅支持 Finder 式键盘首字母快速跳转 `type-ahead`） | 支持在包内按文件名快速检索，无需预先全量解压 | 内置包内过滤与搜索栏，支持按名称、大小等条件筛选 |
| 视图模式 | 统一单大纲列表视图，支持列排序与可调节右侧检查器（240-400 pt） | 列表与快捷预览导向，界面简洁 | 支持列表、图标、分栏视图与内置文本/图片/PDF 预览窗格 |
| 外部编辑自动写回 | 暂未支持（Quick Look 与拖出采用隔离临时目录，不回写原包） | 暂未作为核心工作流主打 | 支持用外部应用打开包内文件，保存修改后自动侦测并写回原压缩包 |

### 1.2 格式与编码能力

参照 Keka 在格式广度上的行业基准，三款产品的读写与编码能力对比如下：

| 能力维度 | BentoZip（当前基线） | MacPacker | BetterZip 6 |
|---|---|---|---|
| 可写/创建格式 | ZIP（AES-256 / ZipCrypto）、7z（支持文件头加密）、TAR、TAR.GZ、TAR.BZ2、TAR.XZ、Apple Archive（`.aar` / `.yaa`） | 侧重常见归档创建（ZIP、7z、TAR 等，相对精简） | ZIP、7z、TAR、GZIP、BZIP2、XZ、DMG、XAR 等；也支持配合外部工具扩展 |
| 只读浏览/解压 | GZIP、BZ2、XZ、ZSTD（`.zst` / `.tar.zst`）、RAR、DMG、ISO、XAR / PKG、CAB、WIM、CPIO、LZMA、DEB、RPM、LZH，以及各类分卷格式 | 基于 7-Zip + XAD / The Unarchiver + SWCompression，覆盖 36+ 格式（含 ZIPX、LZ4、SquashFS、VMDK、SIT/SEA、CBZ/CBR 等） | 覆盖 30+ 格式，除常见归档与 RAR 外，支持 ISO、DMG、VHD、WIM、SquashFS、RPM、DEB、EPUB 等 |
| Zstandard 生态 | 已支持 `.zst` 与 `.tar.zst`（`.tzst`）只读浏览与解压；**尚未支持创建/写入** | 支持读取 Zstd 归档；创建能力视版本而定 | 支持读取与创建（部分版本通过内建或配置参数） |
| 分卷压缩与读取 | **已支持创建** ZIP 与 7z 多卷分卷（10 MB - 4 GB 预设），**已支持读取** `.7z.001`、`.zip.001`、`.tar.001`、`.partN.rar`、`.rNN` 与通用 `.001` | 支持常见分卷读取与解压 | 支持分卷创建与多卷解压 |
| CJK 旧版 ZIP 编码修复 | **已实装**（底层 `zip_encoding` 模块自动探测并转换遗留 GBK / Big5 / Shift-JIS 等非 UTF-8 文件名，列表与解压同步修正） | 依赖底层库，对旧版 Windows 中文 ZIP 偶尔需要手动或默认处理 | 提供手动指定编码的选项，非全自动无感修正 |
| 待补齐镜像与编码格式 | Zstd 创建写入、UDF / SquashFS / 虚拟机镜像（VHD / VMDK / QCOW2 / Ext / APFS）放开、ZIPX / Brotli / LZ4 | 创建侧高级参数（如固实块大小、字典调节）偏少 | 老格式（如 StuffIt）同样依赖旧式解析器 |

|---|---|---|---|

### 1.4 安全与工作流预设

| 能力维度 | BentoZip（当前基线） | MacPacker | BetterZip 6 |
|---|---|---|---|
| 压缩与解压预设（Presets） | 支持保存默认格式、压缩等级、排除规则、自动展开单层顶目录、解压后在访达显示、磁盘缓存上限；尚无多套命名 Preset 切换 | 提供基础偏好设置（智能目录展开等），无复杂多套 Preset 系统 | 核心强项：可配置多套 Save/Extract Preset（指定输出路径、自动剔除 `._*` 与 `.DS_Store`、完成后运行脚本） |
| 密码管理与钥匙串 | 密码按会话提示输入与保留，压缩支持手工输入密码；尚无 Keychain 持久化或密码生成器 | 支持加密包打开与 AES-256 加密创建，无独立密码库 | 内置独立密码管理器（支持 Touch ID 解锁与常用密码自动尝试）及强密码生成器 |
| 包完整性校验与校验和 | 暂未在 UI 暴露单独的 Test Archive 校验动作及 SHA-256 计算面板 | 侧重浏览与提取，校验工具链较弱 | 支持测试压缩包完整性、修复部分损坏头及查看包内 CRC/校验信息 |
| 解压后清理与碰撞策略 | 解压路径冲突与废纸篓自动清理目前未提供精细化策略切换 | 提供基础智能解压目录控制 | 支持解压后自动将原压缩包移至废纸篓，以及丰富的文件冲突处理策略 |
| Collect 跨目录拼包模式 | 暂未支持（当前可通过多窗口或向 `.compress` 队列持续拖入文件替代） | 无专门 Collect 模式 | BetterZip 6 招牌新特性：在访达跨文件夹多次 `Cmd+C` 收集文件到一个新建归档窗口中统一打包 |
| 内建媒体连续查看器 | 借助系统 Quick Look 逐个预览，无内建连续翻页查看器 | Quick Look 原生支持 CBZ/CBR 漫画归档结构预览 | 右侧内置预览栏可直接切换图片、音频、PDF 与代码高亮 |

### 1.5 多窗口与大文件性能

这是 BentoZip 当前版本已经建立起来的结构性优势：

1. **原生的 Document-Based 多窗口架构**：每个压缩包或打包任务拥有独立窗口状态与 `representedURL` 代理图标，天然隔离重复打开同一归档的窗口冲突，比传统单队列/老式 AppKit 窗口更容易同时对照多个归档。
2. **后台大任务与独立 Tasks 窗口解耦**：耗时压缩、解压、修改任务通过 `TransferManager` 统一调度并汇总到独立的进度窗口，支持展开查看类似 7-Zip 的实时速率、已处理/总字节、文件数、实时压缩率与预估剩余时间；将当前窗口返回首页后，后台传输依然继续运行，不会阻塞浏览其他压缩包。
3. **非加密复合 `.tar.*` 持久磁盘缓存**：首次打开大体积 `.tar.gz` / `.tar.bz2` / `.tar.xz` 时自动在 `~/Library/Caches` 建立基于 inode、文件大小和 mtime 校验的 LRU 缓存（可配置上限 `512 MB` - `4 GB` 或关闭），二次浏览、局部拖出和 Quick Look 几乎瞬时完成，同时外层解压阶段也能报告真实进度。
4. **全异步二进制 Unix Socket 通信**：BentoZip 通过长驻交互 worker 与独立重任务 worker 分离，配合约 20 Hz 的进度节流合并，在十万级小文件场景下也不会卡死主线程 UI。相比之下，MacPacker 在超大固实包与重任务隔离上更偏向轻量浏览体验，BetterZip 6 则依赖全局顺序队列（Operations Queue）处理批量任务，界面反馈相对传统。

### 1.6 架构兼容与分发

| 分发与架构维度 | BentoZip（当前基线） | MacPacker | BetterZip 6 |
|---|---|---|---|
| CPU 架构 | 当前工程与构建脚本默认面向 Apple Silicon（`arm64`），macOS 14+ | Universal Binary（同时兼容 Apple Silicon 与 Intel Mac） | Universal Binary（长期兼容 Intel 与 Apple Silicon） |
| 渠道分发 | 已搭建 GitHub Actions 自动构建、Developer ID 签名公证 DMG/ZIP 与 `SHA256SUMS.txt` 发布流程；尚未提交 Homebrew Cask | GitHub Releases、官方网站、Homebrew Cask（`brew install --cask macpacker`）与 Mac App Store | 官网直发（含 Sparkle 自动更新）、Setapp 订阅与 Mac App Store（部分系统扩展受沙盒约束） |

## 二、BentoZip 的差异化策略

### 2.1 对标评价：看清长处与短板

- **BetterZip 6 做对了什么，又为什么显得繁重**：BetterZip 6 把"把压缩包当成可编辑工作区"这件事做到了极致，Save/Extract Presets、Finder 工具栏、独立 Quick Look、Collect 拼包、Touch ID 密码库和外部编辑写回几乎覆盖了重度用户的全部场景。但它的界面信息密度过高、工具栏与设置项历史包袱较重，整体交互仍带有早期 macOS 实用工具的复杂感，上手门槛明显偏高。
- **MacPacker 做对了什么，而 BentoZip 已经在哪些方面领先**：MacPacker 精准抓住了 macOS 用户对"像普通文件夹一样直接预览和翻找压缩包"的诉求，靠开源免费、嵌套下钻、Quick Look 扩展和极低的心理负担迅速积累了口碑。但在真正的生产力硬指标上，BentoZip 目前已经走得更前：**更完整的创建与分卷能力（含 Apple Archive `.aar` 与 ZIP/7z 分卷）、ZIP/7z/TAR 原生就地增删、复合 `.tar.*` 持久 LRU 磁盘缓存、CJK 旧版 ZIP 文件名自动纠偏，以及不阻塞文档浏览的独立 Tasks 实时遥测窗口**。

### 2.2 BentoZip 的产品定位：克制的专业压缩工作台

BentoZip 不追求变成另一个"按钮密布的传统归档 IDE"，也不甘于只做一个"只能看不能改的只读浏览器"。我们的产品原则是：

1. **交互像访达一样自然，性能按工程级工具标准打磨**：主界面坚持零多余 chrome 的 Finder 大纲体验，把复杂的吞吐统计、缓存管理、密码提示和格式细节放到按需呼出的 Tasks 窗口、检查器和设置面板中。
2. **优先补齐日常高频刚需，不盲目堆砌冷门功能**：比如包内搜索、完整性校验、Zstd 创建、Finder 右键与独立 Quick Look 扩展属于几乎所有用户都会高频触达的能力，应优先进入近期版本；而冷门脚本钩子、复杂皮肤或过于极客的界面自定义则坚决不做。
3. **坚持清晰的双层架构边界**：Swift/SwiftUI 只负责原生界面与系统扩展桥接，核心引擎能力沉淀在 `bento7z` 与 `BentoZipCore` 中，保证后续扩展点（Finder Extension、Quick Look Extension、Shortcuts）可以直接复用同一套底层服务与格式探测逻辑。

## 三、分阶段功能路线图（Roadmap）

### v1.1：日常体验与高频刚需补齐

聚焦解决日常使用中最容易感知到的功能缺口，进一步夯实"开箱即用"的主程序体验：

- **压缩包完整性校验（Test Archive）与校验和显示**：在工具栏与上下文菜单提供"测试压缩包"动作，对单个或全部条目执行校验；在检查器展示条目 CRC32 及文件 SHA-256 摘要，方便快速核对下载包。
- **包内实时搜索与筛选（Toolbar / `Cmd+F`）**：在浏览与待打包视图顶部提供即时过滤栏，支持按文件名、扩展名和匹配状态实时过滤节点树，同时保持面包屑与选中状态不丢失。
- **嵌套压缩包直接下钻浏览**：在包内双击内层压缩文件时，自动在受控缓存/临时工作区按需流式解出内层头信息并在当前窗口栈内下钻浏览，支持面包屑一键返回外层归档。
- **Zstandard（`.zst` / `.tar.zst`）写入与创建支持**：打通 `bento7z` 侧 Zstd 编码输出链路，让 `.tar.zst` 不仅能高速只读浏览，还能直接用于高压缩比、高解压速度的日常归档创建。
- **文件碰撞处理策略与解压后清理选项**：解压遇到同名文件时支持"询问 / 覆盖 / 跳过 / 自动重命名"配置；在设置和提取面板增加"解压成功后将原压缩包移入废纸篓"开关。

### v1.2：macOS 系统级深度集成

让 BentoZip 从"需要专门打开的桌面应用"变成融入 macOS 系统工作流的基础设施：

- **Finder Sync 扩展**：在访达右键菜单与窗口工具栏提供 BentoZip 快捷操作，无需预先启动主程序即可对选中文件执行"快速压缩为默认格式"或"解压到当前目录/指定目录"。
- **系统级 Quick Look Preview Extension**：实现独立的 `.appex` 预览扩展，用户在访达、邮件附件或文件选择器中选中任何受支持的压缩包按下空格键，即可直接渲染目录树、大小和压缩率信息。
- **Spotlight Importer 与 Shortcuts / App Intents**：提供轻量包内文件名索引支持（按用户隐私开关控制），并开放"压缩文件""解压归档""列出包内条目"等原生快捷指令动作，接入自动化工作流。
- **Universal Binary 与 Homebrew Cask 分发**：构建覆盖 `arm64` + `x86_64` 的通用二进制版本（同步适配 `bento7z` 与 `7z.so` 双架构产物），提交官方 Homebrew Cask（`brew install --cask bentozip`）扩大直装触达。

### v1.3：高效工作流与安全增强

面向频繁处理多项目打包、加密归档和进阶压缩参数的重度用户：

- **压缩与解压配置预设（Presets）**：允许用户保存多套命名配置（如"发给 Windows 同事：ZIP + 剔除 Mac 隐藏文件""归档备份：7z 最佳 + AES-256"），在检查器、新建窗口与 Finder 扩展中一键切换。
- **钥匙串（Keychain）密码管理与强密码生成器**：依托系统 Keychain 安全保存常用归档密码（支持按用户授权自动匹配解密），并在加密创建界面内置随机强密码生成器。
- **Collect 跨目录渐进拼包与外部修改写回**：支持在窗口进入"收集模式"，从不同访达目录逐步加入文件统一打包；针对可写归档提供"用外部应用打开并在保存后自动写回"的闭环体验。
- **7z 高级压缩参数控制**：在检查器进阶折叠区开放固实块模式开关、字典大小与线程数微调，兼顾常规用户的简洁视图与专业用户的极致压缩率需求。

### v2.0：进阶浏览器与多媒体场景

在稳固主力场景后，适度拓展高价值专业格式与直发渠道体验：

- **轻量内置图片与漫画归档（CBZ / CBR）连续预览**：针对纯图片文件夹和 `.cbz` / `.cbr` 归档提供顺滑的连续翻页浏览视图，无需先全量解压即可快速阅读或挑图导出。
- **虚拟机与系统镜像（VHD / VMDK / QCOW2 / Ext / APFS / UDF）只读浏览**：基于底层已具备的 7-Zip 格式映射能力，按需逐步开放磁盘镜像与文件系统镜像的只读浏览与文件提取，并补充格式识别与安全路径单测。
- **直发渠道 Sparkle 自动更新**：为非 App Store 直发 DMG 渠道集成 Sparkle 增量/签名更新机制，配合 GitHub Releases 实现应用内一键升级。
